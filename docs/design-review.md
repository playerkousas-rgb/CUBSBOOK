# Design Review — 視覺與互動巡檢紀錄

本文件記錄 `CUBBOOK` 在 `390×844`（手機）、`768×1024`（平板）及 `1440×900`（桌面）三個標準斷點，以及 `A4 @media print` 列印模式下的設計規範與巡檢結果（對齊真理倉 `design-review` 技能要求）。

> 誠實聲明：本輪以「全路由伺服器端渲染煙霧測試 + CSS／契約自動測試 + 靜態審視」完成機器可驗部分；**真機手勢、相機掃碼、列印預覽仍須在 iOS Safari／Android Chrome 各跑一次**，未完成前不作「全綠」宣稱。

## 視覺基準（Visual Baseline）

- **布面主色（CUBS Yellow）**：`#f0d85e` → `#ead040` → `#c0a21c`（封面黃布面）；核心值 **`#ead040` 直接取樣自總會《幼童軍紀錄冊》PDF 封面的實測像素**，不用更淺的 `#ffd23f`／`#f2b705`。深墨 `#241605`／`#1a1206` 作燙印文字、內頁標題與次要底色。
- **圖示／favicon（家族版式）**：圓角深金布面（`#664c0e → #3a2a08 → #14100a`）＋內嵌金線＋家族共用水滴環＋幼童軍「C」，金浮雕只用 `#f0d85e → #ead040 → #c0a21c`；16px 手工像素版、maskable 66% 安全區與 OG 圖同源。森林綠、酒紅、海軍藍完全不用，分別留給 `SCOUTBOOK`／`VSBOOK`／`ROVERBOOK`。
- **幼童軍黃（Cub Yellow）**：`#ead040`（主色／官方 PDF 封面取樣）、`#dcc02c`（按鈕底）、`#c0a21c`（暗黃邊框）、`#d6bd67`（燙金點綴）。**黃底文字一律 `#2b1a04` 或 `#1a1206`**；深墨底才可配 `#f2dd76`／`#f2e4b2`。
- **對比陷阱處理**：白字配 `#ead040` 對比僅約 `1.5:1`，設計上全面禁止；深墨 `#241605` 配黃 `11.4:1`、深墨 `#2b1a04` 配黃 `10.9:1`、金黃 `#f2dd76` 配深墨 `12.9:1`、深金標題 `#7a5600` 配象牙紙 `6.0:1`、主墨色配象牙紙 `15.5:1`。`tests/ui_contracts.test.mjs` 及 `tests/parent_mode.test.mjs` 以公式鎖定。
- **紙本內頁（Ivory Paper）**：`#f7f2e7`（紙底）、`#efe8d6`（次底）、`#1e1a14`（深墨）、`#4a4337`（輔助字）、`#6a6152`（第三層字）。
- **字體階層**：標題用襯線體（`Noto Serif TC` / `Songti TC`）呈現正式紀錄冊感；表格與輸入欄用無襯線體（`Noto Sans TC` / `PingFang HK`）；編號、日期、容量計用等寬數字。
- **全螢幕實體書**：封面 `100dvh` 布紋 + 燙金框 + 持有人銘牌 + 五枚獎章章位；內頁為 A4 比例紙張，無卡片框線與陰影。
- **中英完全分離**：頂欄一鍵 `中文 / EN`；`html[data-lang="zh"]` 隱藏內頁英文副標，英文模式全英；不以「中文 English」並排塞入同一表格。

## 巡檢紀錄（Rounds）

### ROUND 1（2026-11-05 · 三斷點 + A4 列印 · 版面契約）

- **範圍**：`/` 封面、`/p/contents` 目錄、`p01`–`p19` 全 19 頁、`/p/appendix` 數位附錄、`/forms` 及 `pt67`（1 頁）・`pt68`（2 頁）・`gbac`（1 頁）・`/forms/all`（4 張 A4）、`/print`（19 頁全冊）、`ShowQrDialog`、`/scan` ➔ `/scan/view` ➔ `/scan/signoff`。
- **機器驗證結果**：以 Node `react-dom/server` 對上述 27 條路由逐一渲染，全部成功（無執行期例外、無 `undefined` 文字漏出），輸出 HTML 由 5.2 KB（封面）至 259 KB（全冊列印）。
- **發現並修正的問題**：
  1. **目錄頁頁碼漏空**：`/p/contents` 因不在 `SECTIONS` 而顯示「第 undefined 頁」→ `Sheet` 改為只在有實際頁碼時輸出頁碼，頂欄與翻頁列改以「目錄」呈現。
  2. **目錄說明仍是舊支部數字**：`IndexDialog` 寫「紙本 40 頁」→ 改為 19 頁。
  3. **手機多欄表格**：`.assrow`（項目｜主考｜日期）與 `.otrow`（名稱｜日期｜證書｜簽名）在 `≤740px` 會擠壓 → 改為單欄堆疊，欄名以 `data-label` 前置顯示，杜絕水平捲軸。
  4. **幼童軍黃對比**：早期沿用深資酒紅按鈕與金色 CTA 混搭（酒紅殘留已清零）→ 改為黃布面配深綠字（`6.9:1`）、深綠按鈕配金黃字（`9.7:1`）、黃色 CTA 配深炭字（`10.2:1`）。
  5. **版權重複**：`/scan` 頁尾沿用 `LegalNote`，令版權聲明出現第四處 → 移除，維持「封面頁腳／數位附錄／選單關於」三處。
- **複驗**：`npm test` 全數 32 項通過（含 19 頁契約、ID 對照、`403` 與 `pending` 契約、`CB1S.` 前綴、WCAG 對比、圖示與 manifest 一致性）；`node scripts/guard.mjs` 16 項全綠；`final_check`／`preflight` 於移除 `dist/` 後通過。

### ROUND 3（2026-11-06 · 圖標家族對齊）

- **範圍**：`/favicon.svg`、根目錄 `favicon.ico`／`favicon-32.png`／`favicon-48.png`、`web/public/icons/` 九件套（含 16px 手繪、maskable、OG 1200×630）及 Service Worker 預快取。
- **改動**：不再自創「黃布面書本卡片」，改用 `VSBOOK`／`ROVERBOOK`／`SCOUTBOOK` 同一基因：圓角布色方塊（radius `0.192`）＋內嵌金線（inset `0.04`）＋單色金浮雕（上方家族水滴環，下方支部圖案）。`CUBBOOK` 的支部圖案定為粗金「C」，與 `VSBOOK` 的「V」同級；`ROVERBOOK` 用缽＋橫桿、`SCOUTBOOK` 用打開的紀錄冊。
- **配色**：布面是幼童軍黃的深色階 `#664c0e → #3a2a08 → #14100a`，金浮雕 `#f0d85e → #ead040 → #c0a21c`；金色只配深布面，沒有白字配黃，也沒有其他支部的綠／紅／藍。
- **並排對照**：[`./icon-family-preview.png`](./icon-family-preview.png) 由四本 BOOK 的 512px 圖標並排組成，肉眼可核對圓角、金線粗幼、水滴環比例與下方支部圖案的視覺重量。
- **機器驗證**：`npm run icons` 重新產生全部圖標，9 件套合計 `173.9 KB`（G11 ≤ 260 KB）；`npm test` 全綠；`web/public/sw.js` 快取升 `cubbook-cache-v5`，避免舊圖示留在離線快取。
- **仍未測**：Android／iOS 主畫面重新安裝後的實際裁切與 WhatsApp／Signal 的 OG 預覽，仍須真機各跑一次；未完成前不作「全綠」宣稱。

### ROUND 2（待辦 · 真機確認）

- **iOS Safari 17/18（390×844）**：`100dvh` 封面首屏、動態島安全區、`Write` 自動縮字、手寫簽名、相機掃碼權限。
- **Android Chrome（412×915）**：虛擬鍵盤彈出時內頁不跳位、二維碼生成耗時、離線 Service Worker 更新提示。
- **iPad（768×1024）／桌面（1440×900）**：A4 紙本比例、整本列印分頁、`/forms/all` 四張 A4 邊界。
- **列印實測**：Chrome / Safari 各列印一次 `PT/67`、`PT/68`、`/print`，確認無頁首網址、無裁切、背景圖形正常。
