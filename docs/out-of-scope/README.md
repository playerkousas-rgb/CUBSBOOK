# Out of Scope — 本專案明確不做事項

為保持 `CUBBOOK` 輕量、離線可靠且私隱零外洩，以下功能明確排除於本倉庫之外（對齊 [`../../SCOPE.md`](../../SCOPE.md) 及七大鐵律第 1 條）：

1. **全團名冊、批量簽核工作台、多成員切換槽**
   - BOOK 一次只服務「這一位」成員。全團進度表、批量 CONFIRM、成員管理一律使用姊妹專案 `cubbadge`（BADGE）；BOOK 只可匯出／匯入單一成員的純進度。
2. **團集會與訓練班教案庫**
   - 不內建集會活動流程設計或教案搜尋（屬姊妹專案 `cubmeeting` 範疇）。
3. **帳號密碼註冊、雲端同步或中央資料庫**
   - 不收集電郵註冊、不接駁外部資料庫、不上傳個人資料或相片。與 `cubbadge` 的連線只傳 SCOUT ID、項目代號及日期；登入 token 只存活於本次工作階段，密碼永不儲存。
4. **取代官方實體蓋印與簽批程序**
   - `PT/67`、`PT/68` 及紀錄冊內頁列印本僅協助成員整齊填報及核對資料；正式遞交時仍須按香港童軍總會規定由團長／旅長簽署、蓋上旅團印，並交由區總監推薦、地域總監批核。
5. **自行編造官方表格或批核欄**
   - 2026 新制金紫荊獎章官方表格尚未公布，`gbac` 只提供明確標示「非官方」的資料核對清單，不設模擬簽署或批核欄。
6. **代成員自我核實進度**
   - 任何由 BOOK 送出的項目只能是 `status: 'pending'`；BOOK 不會、也不能把項目標記為已核實（`confirmedByBadge`）。
